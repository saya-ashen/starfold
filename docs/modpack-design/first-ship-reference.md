# 母星首船参考：B6-F

[阶段3](../escape-velocity-player-guide_zh-CN.md) · [原 B6 分层图](../../tools/ship/minimal.md)

B6-F 是便于手工搭建的开放平台提案，保留自由造船。它继承 B6 的 5×5 甲板、六层压舱、成对六向喷口、双通电陀螺仪和两侧登船梯，在压舱层内加入储罐和货桶。**当前整合包独立供给夹具已通过合计4000mB柴油的近地起飞、平移刹停、着陆、步行登离船和停泊补块；从零生存、满载货运、持续航行及太空航行尚未验收。** 原 B6 的历史操纵数据只属于原布局，不能套用为 B6-F 的承诺。

## 分层与通行

沿用原图坐标：甲板 Y=0，船首向西（−X），每层图从左到右 X=−2…+2、从上到下 Z=−2…+2。原 B6 其余各层保持原图，只把 Y=−3 改为：

```text
TnCnT
wCCCe
BCCCB
wCCCe
TsCsT
```

`C` 为圆石，`T` 为 Create 流体储罐，`B` 为木桶（两端分别朝西、东）；`n/s/w/e` 为朝该方向排气的喷口，推力方向相反。储罐和货桶共替换六块圆石，不占甲板通道，也不挡喷口和登船梯。

四罐保持独立，不要求连管或船载机械泵。储罐有可抽取的流体能力且属于同一物理船体时，推进系统可直接取油。外侧可供地面维护时访问，临时服务平台须留在胶框之外；若使用地面泵加油，飞行前断开岸侧管线，检查没有将岸侧设备粘进船。不要依赖手持桶与 Create 储罐的交互必然成功。

甲板、驾驶台、导航镜、两只陀螺仪及各自拉杆、门与登船梯见原图。每只陀螺仪的拉杆都要打开。驾驶台上方是导航镜，进入驾驶要点中下方控制台。门外及登船梯展开区域保持净空，停稳后才沿梯步行。货桶在下层，停泊时从外侧存取；它不是行进中可直接访问的驾驶舱货箱。

生成完整坐标及部件清单：

```sh
python3 tools/ship/first_ship.py
```

这个命令只打印离线清单，不连接游戏或放置方块。

打磨还需砂纸和纸；六次打磨在一张新砂纸的八次耐久之内。砂纸另用一份沙子，因此玻璃与砂纸至少消耗8沙，不计工坊扩建与失败损耗。正常 Create 纸的压制路线可沿用阶段2。

精密装配每次尝试需要金板1、小齿轮5、大齿轮5、铁粒5，按小齿轮→大齿轮→铁粒重复五轮，共15次部署。当前成功权重120、总权重150，单次成功率80%。得到16个成功构件的期望尝试数为20，**不表示20次必得**。若按24次备料，得到至少16个的理论概率约96.38%；仍须检查实际产物并为失败补料，副产物按实物回收。24次对应金板24、两种齿轮各120、铁粒120、360次部署。这是备料例子，不是修改掉率或必做24次任务。

既有设施单列：压片机、搅拌与热源、部署器、传动、机械合成器、抽油与蒸馏设施、岸侧输油设备。胶和组装器、修理耗材及其配方也须单独按 JEI 核对；不能把本表称作从零开局全部成本。船上货桶提供存储，但当前本体只显式增加推进燃料质量；不要擅自声称每一件箱内货物都已按真实质量计入物理。以实际船体质量与支持的附加质量机制为准。

## 加油、载荷与预算

四罐对称安装，初次向各罐加入相同数量的同种柴油或汽油。当前两者配置均为每 mB 冲量940、每1000mB质量47。**容积不等于允许起飞的加油量**；填满所有储罐会显著增重。燃烧过程中按实际供油顺序抽取，并不保证四罐始终等液位，仍须观察姿态。

先读取实际组装船的干重，再记录加油后的质量和实际有效重力。重力需要计入该星球、所在高度、维度设置及船体重力系数，不能只套用地球9.81或玩家重力。当前船体计算见 `LiftServer.hullGravity` 和 `HullWeight.gravity`。直立、无增强的两只升力喷口总上限为6700；倾斜、堵塞、缺油、未捕获喷口和未通电陀螺仪都使理想预算不足以描述实际表现。

离线预算工具必须显式传入测得或核对后的有效重力。下面仅展示命令格式，**数值是假设算例，不是 B6-F 实测数据，也不是装油推荐**：

```sh
python3 tools/ship/flight_budget.py \
  --dry-mass 320 --cargo-mass 0 --fuel-mb 4000 \
  --fuel diesel --lift-nozzles 2 --gravity 10 --reserve-fraction 0.5
```

四罐的容积只提供储存位置：按上述静态干重、有效重力8.25、直立无额外载荷估算，合计8000mB的推重比约1.16，四罐各填满8000mB则约0.44，无法悬停。这只是说明装满储罐可能超重，不是推荐油量；实际有效重力和质量仍须确认。

工具从仓库配置读取燃料参数和喷口力，报告加油后推重比、初始悬停消耗、扣除预留后的理想悬停时间及空间理论 Δv。悬停持续消耗燃料，供油中断时陀螺仪不会创造升力。理论悬停时间只算垂直承重，爬升、转弯、平移、刹停及重力变化都会改变消耗；空间 Δv 也不是航程或入轨认证。

如果加油后升力不足，先减载/减油或重新设计升力，不能靠陀螺仪解决。增加升力喷口、移动设备、修改压舱均会改变操纵，原 B6 的测量不再适用。先留足母星降落余量；不设固定“八桶入轨”目标，也不把阶段2已蒸馏两桶等同于足够完成首航。

## 首次组装、短飞和修理

1. 平整空地搭建；胶框包含全船、门上半部、导航镜和拉杆，排除地面与临时服务台。空手按住组装器右键，向上移动鼠标拉满，再松开完成组装。当前原生操作会将组装器一起捕获，即使它在全船胶框之外；用镐正常挖回，核对剩余185格及实际质量。
2. 检查六向喷口、两个通电陀螺仪、同船供油、导航镜、舱门与梯道。先从近地短时离地开始，松开升降输入后观察真实刹停，不因原图历史数据而预设松键立即停住。
3. 在起飞点附近练低速前进、转向和刹停，记录前后燃料及载荷。保持足够空域和降落余量；阶段3只做母星短飞，暂不把外星采矿混入这次练习。
4. 着陆停稳，再按实际按键绑定退出驾驶；沿梯离船、再上船并重新驾驶。退出驾驶与离船是不同动作；空中退出驾驶不等于安全降落。
5. 停泊时替换一块容易接近的非关键船壳，再恢复连接并重新验船。若拆装影响船体捕获范围，重新检查组装、油罐与喷口；不要在空中拆关键承力、供油和驾驶设备。

任务中“离地”由进度观察；当地试飞、再登船与维修是明确的手动记录，勾选本身不证明已经做过。下一阶段再处理进入太空、外星锇及同船返航。
