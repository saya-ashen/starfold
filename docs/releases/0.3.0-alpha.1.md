# Starward「向星而行」

This prerelease lists **changes since v0.2.0**. **Create a new world: 0.2.0 saves are not supported.**

## What changed

- **Atlas maps and surveys:** persistent exploration records, ground and globe views, 3D system/interstellar maps, navigation targets and ship tracking.
- **Flight progression:** fuel and component mass affect flight and remaining delta-v; extended destinations and interstellar drive requirements give journeys a clearer progression. Gas-giant pressure and skimming add new flight/resource challenges.
- **Terrain and far views:** reworked deterministic terrain planning, caves, roads, structures and ecology; improved far-view caching, streaming and rendering.
- **Modular content:** Worlds provides experience planets, Extras provides the starter ship/pad/guide, Atlas provides maps, and Materials adds lightweight aluminum plating and osmium pressure hulls. These are separate from the core jar.
- **Biotech:** optional Flesh hive terrain, blood, organic materials and the Host encounter. Balance is provisional.
- **Ship persistence and recovery:** improved return flights and recovery of saved ship dependency groups through map targets, including reboarding the original ship after restart.

## Downloads and installation

- **`Starfold-Experience-0.3.0-alpha.1.mrpack`** — import into a launcher supporting Modrinth packs. Includes the six Starfold player modules; the launcher downloads pinned Sable 2.0.5, Create 6.0.10, Create Aeronautics 1.3.2, Immersive Aircraft 1.5.2 and GeckoLib 4.8.2. Create a new **Starfold: Experience** world for the starter ship.
- **`starfold-0.3.0-alpha.1.jar`** — core mod for a manual installation; requires Minecraft 1.21.1, NeoForge 21.1.247+ and Sable 2.0.5 or 2.0.6.
- **`starfold_worlds`, `starfold_extras`, `starfold_atlas`, `starfold_materials`, `starfold_biotech` JARs** — optional player modules, all version 0.3.0-alpha.1. Extras needs Worlds, Create and Create Aeronautics. Biotech needs Worlds and **exactly GeckoLib 4.8.2**. Use matching Starfold module versions and remove old jars.
- **`INSTALL.txt`** and **`SHA256SUMS.txt`** — installation details and checksums.

## Alpha limits

Single-player remains the validation target. Use the vanilla renderer; shader packs are unsupported. The Experience download has a starter ship and does **not** include the unfinished survival quest pack. Full survival equipment/oxygen/fuel progression, balance and multiplayer have not been accepted. Planet planning may cause noticeable pauses, and partial failures during native multi-ship restoration do not yet have full transaction rollback. The optional seasonal display module is excluded while its third-party provenance review is pending; core climate APIs remain.

Validation: JDK 21 build/check, 1,867 Java tests, offline tool checks, packaged mixin contracts, Sable runtime and module packaging checks. Prior in-game return/restart/reboarding checks used creative flight and do not certify a full survival playthrough.

# 向星而行

本次仅记录 **v0.2.0 之后的更新**。**不兼容 0.2.0 存档，请新建世界。**

## 本次更新

- **Atlas 星图与测绘：**持久化探索记录、地面与球体视图、三维星系／星际地图、导航目标和飞船追踪。
- **航行进度：**燃料和组件质量参与航行与剩余 Δv 计算，扩展目的地与星际引擎要求；气态巨行星压力与采集带来新的航行和资源挑战。
- **地形与远景：**重做确定性地形规划、洞穴、道路、结构与生态，改进远景缓存、流式同步和渲染。
- **内容模块化：**Worlds 提供体验星球，Extras 提供起始飞船／停机坪／指南，Atlas 提供地图，Materials 提供轻质铝外壳板和锇耐压壳，均独立于核心 JAR。
- **Biotech：**可选的血肉虫巢地形、血液、有机材料和宿主遭遇，平衡数值仍为暂定。
- **飞船保存与恢复：**改善返航，以及通过地图目标恢复相互依赖的存档船组，包括重启后重新登上原船。

## 下载与安装

- **Experience `.mrpack`：**导入支持 Modrinth 整合包的启动器，内含六个 Starfold 玩家模块，启动器自动下载固定版本依赖。新建 **Starfold: Experience** 世界即可获得起始飞船。
- **独立 JAR：**核心需要 Minecraft 1.21.1、NeoForge 21.1.247+、Sable 2.0.5 或 2.0.6。按需添加其他模块；Extras 需要 Worlds、Create 和 Create Aeronautics；Biotech 需要 Worlds 和**固定版本 GeckoLib 4.8.2**。Starfold 模块请统一使用本次版本，安装前移除旧 JAR。
- 安装细节见 `INSTALL.txt`，文件校验见 `SHA256SUMS.txt`。

## Alpha 限制

目前以单人为验收目标，需要原版渲染器，不支持光影。Experience 包提供起始飞船，**未包含尚未完成的生存任务整合包**；完整生存装备／氧气／燃料流程、平衡和多人尚未验收。星球规划可能出现明显停顿，原生多船恢复在部分失败时尚无完整事务回滚。季节显示模块因第三方来源审查未完成而暂未包含，核心气候 API 保留。

验证包括 JDK 21 构建、1,867 个 Java 测试、离线工具检查、打包 mixin 契约、Sable 运行时和模块边界检查。此前游戏内的返航／重启／重新登船检查使用创造飞行，不代表已走通完整生存流程。
