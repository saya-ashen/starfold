# Starfold / Escape Velocity 玩家手册

从一张床、一座矿井开始，在母星造出第一艘能飞、能降落、也能修的船。第一次外星航行把锇带回工坊，下一步用液氢扩大活动范围。最后，从气态巨行星取氘、挑战血肉卫星上的宿主，造出星际引擎。**主线的终点是一趟完整远征：在另一星系着陆，建立能保存重进的据点，再驾驶原船把货带回母星。**

本手册面向 Minecraft **1.21.1 / NeoForge 21.1.247** 的 Escape Velocity 单人生存开发版。后半部分包含资源位置、Boss 和星际配方剧透。游戏内物品名称和配方以当前任务书与 JEI 为准。

## 1. 你可以怎么玩

| 内容 | 玩起来是什么样 |
| --- | --- |
| **Starfold 本体** | 在六面连续的方块星球上徒步、造基地和挖矿，能从一个面走到另一个面，也能驾驶自造飞船离开地表。近处地形是真实区块，远处能看见星球轮廓。太空中的行星和卫星会沿各自轨道移动。 |
| **Worlds 与 Atlas** | Worlds 提供体验宇宙和不同类型的星球。Atlas 提供地面、行星、星系和星际地图，支持航点、船只记录与已发现的探矿结果。 |
| **Mining 与 Materials** | 用固定采矿平台减少手挖，用紧凑抽油机取得原油。用铝板减轻船体，用锇耐压壳保护特定部位。两套设备都可以从早期固体燃料起步。 |
| **Biotech** | 探索血肉卫星 Flesh 的巢穴，挑战宿主，取回制造星际引擎所需的神经节。 |
| **Escape Velocity 整合包** | 从空手开局。Create、Aeronautics 和 Sable 负责机械与船体，Create Diesel Generators 负责炼油，Mekanism 提供外星金属开启后的电力和制氢路线。整合包调整了矿物分布与配方，FTB Quests 带你走过九个章节、110 个任务。 |

如果只想先试飞，可以另开一个装有 **Worlds + Extras** 的体验世界，使用提供的起步船。**Escape Velocity 主线使用没有赠送船和停机坪的生存预设**，第一艘运输船要自己造。本体也提供个人推进背包，适合单独体验飞行。手册以下按整合包的造船与运输路线展开。

## 2. 开档与常用操作

- **安装。** 当前开发版的 Packwiz 导出需要另配同版本的六个 Starfold JAR，依次为 Core、Worlds、Atlas、Materials、Mining 和 Biotech。使用整合包固定的外部模组版本，并随实例安装 `config/` 和 `kubejs/`。整合包安装说明列出了所需文件。 [安装说明](../modpack/README.md#local-starfold-jars--required-before-testing)
- **新建世界。** 在单人模式新建生存存档，确认选择 `starfold_worlds:experience`。该预设在整合包中省去出生舰、下界和末地。旧档留作备份，尤其是换开发版或改实例配置前。
- **打开任务书。** 从背包侧栏点 FTB Quests 的书形按钮。物品任务看背包，进度或击杀任务看游戏事件，带勾选框的任务由你在实际完成操作后确认。标为可选的运输、设备和库存样本可以留到有需求时做。
- **查当前配方。** 在 JEI 指向物品按 `R` 看配方、`U` 看用途。界面关闭后，驾驶状态下的 `R` 默认用于退出驾驶。键位冲突时到控制设置里改键。
- **地图和指南。** 默认 `M` 打开 Atlas。天黑前先给基地做航点。首次入档会收到开局指南，丢失后可在背包有空栏时用 `/starfoldguide zh_cn` 补领。星图里的“接近”用于移动观察视角。驾驶时用“设为导航目标”才会向飞船发送导航请求。

## 3. 从开局到返航

### 阶段 1 · 先把母星住下来

1. 在母星 **Hearth** 找一块有木材、食物、水源和回家路线的安全地面。先做石器、火把和熔炉，再做床、封闭照明住所与仓库。睡过床后检查床边有重生空间。工具、食物和火把留一套在家，死亡后的回收按存档原有规则处理。
2. 用 Atlas 标记住所、矿口和岸边。星球由六个相接的面组成，可以步行跨面。回家时结合地图航点和地貌识别位置。八个角是折点异常区，早期绕开。
3. 手挖启动用的铁、铜、煤和安山岩，看到锌一起收集。FTB Ultimine 的激活和形状键可在控制设置中查看，最多一次 32 格，需要合适工具，会额外消耗饥饿和耐久。在洞顶、水边或脚边先用小范围试挖。母星的金和红石在更深处。母星矿表没有锇，也没有钻石，造首船无需等到这些材料。
4. 想减少下矿次数，用 **4 铁锭、2 铜锭、铁镐、熔炉、拉杆**做固定采矿平台。选好井位，从界面开始探矿，给煤或木炭，也可接 FE。探矿后按可采目标逐步开挖，安排废石和矿物的输出空间。平台在区块卸载或所有者离线时暂停。Atlas 显示的是你的历史探矿结果，开采后在现场确认剩余矿点。 [矿机界面与模式](../mining/README_zh-CN.md#制作与使用)

**何时进入下一阶段**：你有能稳定返回的落脚点，能反复取得铁、铜、燃料和安山岩，也知道怎样继续找锌、金和红石。村庄、沉船和废矿井值得经过时探索，开局不要求找到其中任何一个。

### 阶段 2 · 建水力工坊，做出两批燃料

1. **先建能反复运行的工坊。** 手工安山合金起步，用水车、轴和齿轮搭起动力网，首先接机械压机、盆与搅拌器，再加部署器。机器不动时检查输入、水车方向、速度与应力。两个普通水车合计 512 SU 的参考配置足够让压机、搅拌器、部署器各以 32 RPM 工作，继续接磨粉机或泵时要留应力或另供动力。
2. **把黄铜和精密构件做出来。** 用铁板、煤炭块和铜做烈焰人燃烧室；煤炭同时要留给点火和冶炼。给搅拌盆加热，铜和锌制黄铜。红石加玻璃做玫瑰石英，打磨后配铁板做电子管。精密构件用部署器按“小齿轮 → 大齿轮 → 铁粒”循环加工金板。它有失败产物，按到手的成功件数备料。需要强力胶时可查 JEI 的面团加黄绿色染料路线。
3. **勘探天然油藏。** 用铁、铜、铁栏杆、空桶、熔炉做紧凑抽油机，靠固体燃料或 FE 供能。先勘探，再让设备钻井和抽油。无油、井路被流体或方块实体挡住时，换井位或排除障碍。它和 CDG 大型抽油设备使用同一有限油藏，重复开机不会补满油田。
4. **炼油并收进独立储罐。** 用空的 `1×1×3` Create 储罐与 CDG 控制器组装蒸馏塔，按自下而上布置原油输入、柴油输出、汽油输出。各层管路分开，机械泵确认朝向与动力，按任务指引给塔加热。先做一批，确认原油进入塔且成品到了对应罐，再取得第二批。母星船可用柴油或汽油，制造和短飞消耗会从同一库存里扣除。

**何时进入下一阶段**：能稳定补做黄铜和精密件，知道油从哪来、怎么输进船罐，并保留了第二批燃料。任务书里的旋翼运输、大型抽油机和其他选做设备可以按兴趣发展。 工坊及蒸馏参考

### 阶段 3 · 造一艘能回来的首船

1. **照着一艘小船练习。** B6-F 分层图和备料表提供一艘 185 格的参考船。它用 12 个六向推进器、2 个通电陀螺仪、驾驶台、二级导航观察镜、4 个流体罐、货桶和登船梯。按该布局需要 16 个成功的精密构件。首航导航镜用母星工坊就能做，锇留给后续设备。
2. **组装前检查捕获范围。** 用胶连接全船，包括门上半部和驾驶设备，排除地面和临时支架。空手按住原生物理组装器右键，向上移动鼠标拉满再松开。当前版本有可能顺带捕获组装器，停稳后可用镐挖回。按实际捕获的方块、喷口方向、梯子和舱门检查一次。
3. **少量加油、先试升再试停。** 用岸侧输油设施向同船兼容储罐加油，比较加油前后质量，确认供油能到喷口。油罐装满有可能让船飞不起来。陀螺仪用于稳定姿态。先在平坦空地短时离地、低速移动、转向和刹停，最后完整降落。把升力测试、返航燃料和储备分开算。
4. **把重登和维修练一遍。** 等船停稳，退出驾驶，沿梯下去，再从原地登船并接管。停泊时试修一块非关键船壳，确认连接与部件都还在。将基地、油站和练习停泊点标在地图上。

| 场景 | 默认驾驶操作 |
| --- | --- |
| 近地驾驶 | `W/S` 前进或后退，`A/D` 转向。`空格` 增加升力，`Shift` 降低升力。`Ctrl` 配合方向或升降可加力，低空初练用短输入。 |
| 太空驾驶 | 鼠标转向，`A/D` 滚转，`W/S` 调整前进油门与减速。用仪表看相对目标的速度与距离，提前留出制动空间。 |
| 操作与降落 | 默认 `R` 离开驾驶台。先降落、停稳并确认可下船。若已进入星球的自动抵达流程，默认 `空格 + Ctrl` 可中止，随后主动飞离。自动抵达仍需驾驶员找安全地面。 |

**何时进入下一阶段**：你能用同一艘船完成起飞、转向、刹停、落地、重登和一次停泊维修。一次近地短飞的耗油量只用于这次练习的记账，跨星球出发前要另算。

### 阶段 4 · 首次跨星采锇往返

1. **选目的地。** 在 Atlas 比较母星小卫星 **Fleck** 和岩质星 **Anvil**，两者对应的类型都能产锇。首航可优先比较 Fleck 与当前位置的距离和相对速度。它们位于母星系内，可以用常规燃料。带铁镐、食物、照明、维修件、备用材料，并留出货舱和撤离路线。
2. **先算回家的油。** 把母星起飞、去程加速、目标制动与落地、外星起飞、回程加速和母星落地分段记账。记录每罐读数和停泊点。可以在驾驶状态用 `/starfold mark add home` 留下基地标记，用 `/starfold mark list` 核对。起飞点随星球记录，返航前确认目标是母星的基地标记。
3. **落地后采矿、装船。** 根据 Atlas 定实际目标，接近时按相对速度制动并找平坦地面。停稳后标出飞船与矿口。用铁镐取至少 **8 份原锇**，装进原船货舱。准备马上扩建液氢工厂时可以多采，建议把原矿留一部分做粉末。返程前复核实际湿重、升力与剩余燃料。
4. **母星交货并开工。** 用原船返航，把原锇卸进基地仓库后再冶炼，完成出发、装货和卸货的任务记录。用热力发电机供电给冶金灌注机，生产首批基础控制电路，为下一阶段搭电力网。 采矿往返与启动材料表

### 阶段 5 · 把一次出游变成一条补给线

1. **制造液氢。** 给 Mekanism 电解分离器供水供电，使用化学管路将化学氢送进设为冷凝模式的旋转冷凝器，再用流体管路将液氢送入兼容储罐。氧气出口要有去处，氧气积满会停产。先生产、存好一批，再实做第二批，确认船上储罐能向推进器供油。离线或停机后回来，先检查机器端口和储罐液位。
2. **按需求改船。** 沙漠星的铝土矿用于制作轻质铝板。分批替换船壳并复测姿态、湿重和燃油；轻量化可以提高原喷口的起飞余量。高级电路和晶体星的萤石能升级精密观察镜。采气口和其他设备也会吃高级电路，按用途分开准备。耐压壳是后面的专用重件，测试加装后的真实起飞质量。
3. **复跑一条你会用到的资源路线。** 可以补锇、运铝，或者取精密镜用的萤石。预先确定卸货仓、维修点和下次出发燃料。锡、铅、铀等材料按实际要做的设备取，不必为了开新章把所有星球都跑一遍。 液氢、改装与补给参考

**可选进阶采矿。** 从外星带回锇、发展 Mekanism 工业后，可以用 **数字型采矿机（Digital Miner）**替代基础采矿平台。首航仍可用铁镐取锇。配方需要原子合金等进阶材料，在 JEI 搜索「数字型采矿机」查看完整配方。部署后接电和收纳，先缩小半径与高度范围，只给目标矿石设过滤器，确认出货后再扩大范围。六面星球的接缝行为尚未验证，初次使用先把范围设在同一面内。

### 阶段 6 · Amber 取氘，Flesh 取神经节

完成重复补给路线后，两条支线可以并行，也可以按你手头的装备自由决定先后。

**采气路线。** 用精密构件、两个高级电路、Create 流体储罐和旋转冷凝器造采集口。把它和另备的空兼容储罐装进同一艘 Sable 船。到 Amber 气层外先试好制动和退场方向，然后从外侧低压区采集，观察压力、液位和损伤。有氘进入罐后撤出，确认产量停止，再返回收取第二批。任务书里的 8,000 mB 满罐记录只说明这只罐的液位，远征需要另列去程与返程预算。

普通部件与铝板从压力 **0.5** 起可能受损，锇耐压壳阈值是 **0.85**。耐压按实际部件判断，尽量让全船最脆弱的部件都远离阈值。模型中的参考压力不是目标压力，低于 0.5 也能采到氘。带一批常规应急燃料，给制造用的氘桶与航行用的氘分别留量。用有动力的机械泵给 Create 注液器供氘，在下方置物台或传送带放空桶，灌出一桶用于合成。

**宿主路线。** 在 Atlas 找 **Flesh**（血肉／髓原，Amber 的外侧卫星），先安全停船，再带护甲、远程武器、弹药、食物和恢复物资进入巢穴。标记着陆点和退路，必要时把多余装备放在战斗区外。自然遭遇只在指定巢坑附近触发，到了卫星或普通巢穴旁仍需找到战场。战斗先拆囊体，囊体仍活着时地面阶段的宿主承伤很低。每次转阶段先看撤退路线，再继续输出。

> **存档规则**
> 每颗带有巢穴的星球独立记录 Host。每次击败固定掉落四个神经节，经过七个游戏日后会在同一颗星球的巢穴再次出现。取到后尽快带离战斗区并分开存放，至少为第一台引擎留一个。

### 阶段 7 · 造引擎，完成第一次星际远征

1. **合成并安装星际引擎。** 用 10 台有旋转动力的 Create 机械合成器排下图。两侧朝中间汇入，中列向下输出，并在底部接引擎和返还的空桶。`H` 是 4 块锇耐压壳，`C` 是 4 个精英控制电路，`D` 是 1 桶氘，`G` 是 1 个宿主神经节。把成品装在与主推进器和燃料罐同一船体上，核对改装后的湿重，再试本地起降。 合成阵列与采气设备详解

   ```text
   H C H
   C D C
   H C H
     G
   ```

2. **选具体星球，并做双向预算。** 在 Atlas 星际图选恒星系，再查看该星系并选一个能着陆的星球。驾驶台配二级或三级观察镜，设置导航目标后看 HUD 是否生效。预算去程加速、巡航修正、目标制动、落地、返程起飞与返程制动。把返程和应急氘量单独划出来。离开母星系范围后，推进和制动都需要同船引擎及可抽取的氘。惯性仍会带着船往前，到了另一个星系也要继续保留氘来刹停和返程。
3. **着陆、建据点、保存重进。** 接近目标时看相对速度，提早减速，把导航切到实际要落的行星。选有净空的地面，停稳再离船。建有照明的住所、仓储和补给点，保留足够维修件和兼容燃料。保存退出前记下航点、船只、燃料和货物；重进后先核对再启程。当前路线不假定新据点所在的星球能生产氘。
4. **开原船回 Hearth 并卸货。** 回到母星，核对货物、燃料和停泊状态，补充下一航次的物资。任务里手动填写着陆、据点重进和返航等记录。做到这里就完成了第一轮生存主线，可以把据点扩成补给站、建设更多采矿路线，或者用同一套飞行规则探索其他星系。

## 4. 航行应急与收工检查

| 遇到的问题 | 先做什么 |
| --- | --- |
| 飞船不起飞或带货后升不起来 | 就地检查喷口方向、是否捕获、剩余燃料、罐是否可抽取、陀螺仪通电和实际湿重。安全停泊后减载、减油或重新设计升力。 |
| 看得到目标，仪表却没导航 | 确认在正确船上接管且有导航镜，使用 Atlas 的“设为导航目标”。接近另一星系后重新选该星系中的着陆行星。 |
| 锁定目标却越飞越难停 | 依据目标相对速度提前制动。越过母星系前亲自试一下同船引擎和氘的供油链，对目标附近的制动与返航单独留储备。 |
| 离船后找不到船 | 回地图中的停泊标记，结合 Atlas 船只记录找回原船。保存退出选船停稳时，记录标记、燃料和货物。 |
| 回程燃料不够 | 先停泊，保留剩余燃料。安排基地送油或救援。母星系外需要具备星际推进资格的救援船。 |
| 机器有动力却没有产物 | 分开检查原料、转速或电力、进出侧、泵方向和输出空间。电解要检查氧气，抽油要检查储量，蒸馏要检查加热和各层液位。 |

每次长航前可以用一张便签记录：**船只、出发站、目的地、备降点、各罐液位、去程与返程储备、货物数量和最后一次安全保存的位置**。新改的船先跑一遍当地起降和重登，找到兼容供油再考虑出远门。

## 5. 远征之后

第一次星际返航完成后，你可以自己决定下一趟为何出发。把外星据点扩成补给站，用货船往返母星和矿区；也可以为采气专门造一艘船，或给测绘船减重，去记录还没走过的海岸、环形山和卫星。已有的工坊、航点和物资可以继续服务这些目标。

更长远的展望是让不同星系各有值得造船前往的理由。有的世界适合建矿场和补给港，有的值得为了地貌、遗迹或独特的生物遭遇专程远征。飞船也可以有更鲜明的分工，从往返固定航线的货船，到在陌生星球独立作业的勘探船。随着航线延伸，最初只为返航准备的一座小据点，可以逐渐成为通往更远星系的下一站。
