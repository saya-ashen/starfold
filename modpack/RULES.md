# 现行整合包规则

本文件按当前受版本管理的资源、配方和任务整理。数值仍属暂定；旧实测仅见 README 的历史说明，不代表当前生存流程或燃料平衡验收。修改规则须同步资源与离线合同，不能用旧归档覆盖当前资源。

- Minecraft 1.21.1 / NeoForge 21.1.247；外部模组版本由 `mods/*.pw.toml` 固定。Aeronautics 包含 Offroad/Simulated，Sable 单独固定；不包含 BOMD。GeckoLib 固定 4.8.2（文件 7023453）。
- 本地发行组成是 core、Worlds、Atlas、Materials、Mining、Biotech 六个 JAR。Extras 不加入这个从零开始的生存包；probes/devtools 为开发工具。未发布的本地 JAR 不能伪造 CurseForge 元数据，也不能混进 overrides。
- `starfold_worlds:experience` 为新世界预设，无出生舰/平台、下界、末地。具名母星系由 Worlds 提供；体验宇宙配置母星系之外的8颗额外恒星（当前配置新建世界共9颗太阳），其他星系行星数配置2–3，Biotech 在 Amber 最外侧追加 Flesh（髓原）并扩展宇宙类型列表；KubeJS 不覆盖这些星系/宇宙定义。
- 12 个 Worlds 类型的 KubeJS 覆盖调整矿表；母星额外指定原版结构集合、关闭结构损坏与掩埋，并在原陆地群系和材质规则之前追加深浅海气候分区与湿海床规则；其余地形字段及矿物顺序保留。母星及其余宜居类型没有锇或钻石；岩质/小行星有锇和深层钻石，晶体星也有更稀少的深层钻石。钻石深度 0.65–1，稀有度分别 0.99 / 0.995。沙漠唯一放置 Materials 铝土矿，Materials 自身不注册生成。
- 母星浅层增加安山岩，结构仅启用村庄、废弃矿井、沉船、海底废墟四组，损坏与掩埋均为 0；不保证出生附近必有结构。整包出生选点检查天然安全地面及附近原木、水源，不生成启动资源。
- 首次加入获得中英文各 18 页的原版成书指南，领取记录持久化；非 OP 可用 `/starfoldguide [zh_cn|en_us]` 免费补领，冷却 600 游戏刻。死亡和难度规则沿用存档设置，不增加墓碑、免费装备或保护区。
- FTB Ultimine 固定 NeoForge 2101.1.15，最多 32 格，要求适用工具，消耗正常耐久及额外饥饿。白名单为矿石、主世界基础石材与原木，不对机器或容器启用；天然与玩家放置的同种原木/石材无法区分。
- Mining 提供固定采矿平台：4 铁锭、2 铜锭、铁镐、熔炉、拉杆合成；5×5、最深 512 格，先探矿后逐层真实开挖。可插燃料或接 FE，共用 20000 FE 储能；扫描每格 2 FE、实际开采每方块 80 FE，默认每 10 刻一块，18 格输出。区块卸载或所有者离线暂停，不支持船上或离线开采；Atlas 可查看私有历史探矿结果并使用普通航点导航。
- Mining 另提供 `oil_extractor`：4铁锭、2铜锭、铁栏杆、桶、熔炉合成，使用真实CDG区块油藏，不安装CDG时明确停用。勘探1000 FE，虚拟井最深1024格、每层80 FE/10工作刻，抽油100 mB/20工作刻、每实际mB扣2 FE，内部罐16000 mB；有限油藏枯竭明确写0。沿井逐层检查地层与保护，拒绝流体／方块实体／非地层，复核回调后的实际状态；所有者离线或区块卸载暂停。支持20,000 FE储能和熔炉燃料；流体能力只出不进，管道和空桶可取出原油。Atlas油田记录未接入，操作面板可独立使用。
- Create 支撑初始机械工业和导航镜；导航镜在首次起飞之前，不需要锇。无下界的烈焰人燃烧室和玫瑰石英配方避免启动死锁。外星锇开启 Mekanism，精密镜仍需高级电路与萤石。
- 柴油/汽油、氢、氘的冲量依次为 940、1880、23500，质量均为 47 / 1000 mB。只有氘可用于星际推进；离开母星系后的推力同时要求同船星际引擎和氘，不阻止惯性滑行。具体燃料定义在 `kubejs/data/escape_velocity/starfold/thruster_fuel/`。
- 氘来自 Amber 气压场中的采集口，参考压力 0.5 时产率 10 mB/tick；重水分离配方禁用，旋转转换只转换已有氘。普通方块耐压阈值 0.5，锇耐压壳 0.85；按各方块判定，不是整舰护盾。
- 每颗带有巢穴的星球独立记录宿主遭遇。击败后经过七个游戏日，再接近巢穴可触发重生。每次掉落四个神经节。星际引擎使用 Create 3×4 机械合成：四块锇耐压壳、四块精英电路、一桶氘、一个宿主神经节。精确 recipe 以 `kubejs/server_scripts/progression.js` 为准。
- 九章共 110 个任务，双语键一致，原 87 项 quest/task/reward/chapter ID 不变。航空、CDG 大型抽油机、机械合成阵列与 Create 交流发电机为可选分支，不阻塞地面燃料和首船主线；导航镜、组装器、胶与第二批燃料必须先于首航。第七章旧 ID `1000000000070500`–`1000000000070700` 保持退役；新 Flesh 记录使用后续 ID。引擎任务显式依赖击杀宿主记录。
- 首次采矿往返增加出发登记、装矿返程复核和同船卸矿三项手动记录，原锇在母星卸货后再冶炼；离线日志只核对人工声明一致性，不认证同船或矿物来源。
- 阶段5增加液氢复产、运输船升级核算与重复资源路线三项手动记录；不冒充生产或运输遥测。锡、铅、萤石样本、铀、残骸、碎片、流体罐与多用工具为可选分支；精密镜所需萤石仍须按配方准备。轻质板和高级电路、精密镜为升级教学，离线质量/Δv不证明实船载货或操纵。
- Flesh 着陆、进入巢坑、装满 8000 mB 储罐和离开母星系是明确的手动记录，不冒充地点/液位遥测。宿主用 kill 任务，现有飞行 advancement 用既有事件验证。

## 维护与验收

从仓库根执行 `python3 tools/modpack/check-modpack.py` 检查资源、pins、配方、任务、索引和发行清单；`--with-jars` 才读取已缓存外部 JAR 进行哈希、标签、配方与依赖闭包检查。两种模式均不下载、不运行 Minecraft 或外部 JAR。

`python3 tools/modpack/generate-quests.py --check` 在临时目录复现并逐字节比较任务文件；`--output <directory>` 才生成到指定位置。`inventory.py` 默认只使用缓存并写 `build/modpack/ids.json`，下载必须显式 `--fetch`。生成审计、下载和导出保留在 build，脚本保留在 tools，规则不得依赖个人归档路径。

Packwiz 排除本文件、README、ID 清单、Python 工具和本地 JAR。任务章节使用稳定章节 ID 文件名，生成器迁移旧序号文件名，避免 FTB Quests 保存后产生重复章节；原任务 ID 保留，新增采矿平台与阶段二实际加工、抽油补充及可选运输任务。离线通过不证明游戏兼容、油田可用性、宿主生成或生存往返完成。

- 阶段6的采气与宿主路线从重复资源路线并行开放，在引擎制造前汇合；通用钢材、铁块、精英电路样本和终极罐为可选库存提示，实际配方材料不豁免。
- 阶段6–7新增撤离复采、同船安装、目的地/返航预算、另一星系着陆、据点重进、返航补给六项手动记录，不提供自动同船/目的地/据点认证。首个远征目标包含据点与返航，后续探索开放。
- 母星系外推进资格按同船引擎与interstellar燃料判定；氘冲量23500，质量47/1000mB，普通燃料质量仍计入。多航段工具显式声明边界与引擎，不推断地图、航线或实际可达。
