---
title: "Preflight Checklist"
---

- Record the ship, departure point, destination, and alternate landing site. Verify base, landing, and parking waypoints.
- Record cargo quantities, actual wet weight, available lift, and every tank level. Verify that fuel can be drawn.
- Budget outbound fuel, return fuel, landing reserves, and emergency fuel separately.
- Check for damage and make repairs. Load tools, food, lighting, and spare parts.
- Record where you last saved safely.

| Flight | Additional checks |
| --- | --- |
| Local practice | Check that the ship’s gyroscopes are powered. Practice lift-off, braking, landing, and reboarding in an open area. |
| Mining | Pack an Iron Pickaxe and leave cargo room. Recalculate return fuel after loading. |
| Deuterium collection | Test braking outside the atmosphere. Pick an exit heading, check the weakest exposed part, and keep separate flight reserves. |
| Interstellar | Verify the onboard drive and deuterium feed. Set aside fuel for destination braking, the return trip, and emergencies. |
