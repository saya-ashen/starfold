This handbook covers the **Escape Velocity single-player survival Alpha** for **Minecraft 1.21.1 / NeoForge 21.1.247**. Check the quest book and JEI for current item names and recipes.

1. Install [Escape Velocity on CurseForge](https://www.curseforge.com/minecraft/modpacks/starfold-escape-velocity) in a separate game instance. Use Java 21 and keep the mod versions specified by the pack.
2. Create a **single-player Survival world**. You start without a ship or landing pad, and there’s no Nether or End. Back up your save before updating the pack or changing instance settings.
3. Open **FTB Quests** from the inventory sidebar. Item quests check your inventory; advancement and kill quests track in-game events. Check off manual quests only after doing the work. In JEI, hover over an item and press `R` for its recipe or `U` for its uses.
4. Press `M` by default to open Atlas and mark your base.
