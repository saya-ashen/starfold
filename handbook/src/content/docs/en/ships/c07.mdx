The C-07 is an **optional carrier schematic** built in sections at a shipyard. Use the exterior view above Fleck to see the overall shape, then use the placement diagram to plan space for the build and assembly.

1. Import the sections using the general schematic instructions. Follow the matching offset table and orientations from a common reference point. Preview each seam before building.
2. When construction is complete, check that the four hull sections join as intended. Assemble each door and the shuttle as separate bodies from the carrier. Verify the blocks to capture, thruster directions, Ship controller, and gyroscope power. Keep the shipyard and supports out of the assembly.
3. Add a little fuel on Hearth. Use actual wet weight and the working fuel feed to practice takeoff, landing, braking, and reboarding.

<div className="hb-callout hb-callout--check">

**You’re done when** the sections align, the controls and fuel feed work, and the ship has completed a local takeoff and landing.

</div>
