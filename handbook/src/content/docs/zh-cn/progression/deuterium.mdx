1. 用 **1 个精密构件、2 块高级控制电路、1 个 Create 流体储罐和 1 个旋转冷凝器**制作气体采集口。把它和兼容空罐装在同一艘组装船上。另备常规应急燃料和维修件。
2. 在琥珀气层外试制动，确认可用推力和退场方向，再从外侧低压区进入。看采集口压力、HUD 的「整舰气压估计」、液位和损伤。船体局部压力可能比采集口更高。
3. 在最弱暴露部件达到耐压极限前，沿预选方向退出。做**两次独立采集**，每次都安全撤离，分别记录采集口压力、船体承受的最高压力、液位、损伤和推进燃料余量。
4. 用有动力的机械泵把氘送进 Create 注液器，把置物台或传送带上的空桶装入 **1,000 mB**。不要拿桶直接右键普通储罐。

| 部件 | 压力判定 | 保护范围 |
| --- | --- | --- |
| 普通部件与铝合金外壳板 | 从 **0.5** 起可能受损 | 各方块独立判定 |
| 锇合金耐压壳 | 耐压阈值 **0.85** | 只保护该方块，不保护其他船件 |
