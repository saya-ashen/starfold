1. 用水车、轴和齿轮搭起动力网，先接机械压机和搅拌器，再接部署器。机器不动就查水车方向、转速和应力；超载时分开供能。
2. 整合包可用 3 块铁板、1 个煤炭块和 1 个铜锭制作烈焰人燃烧室。安装后加入燃料，在燃烧室加热的搅拌盆中，用机械搅拌器混合铜锭和锌锭，制成黄铜。用红石和玻璃制成玫瑰石英，打磨后配铁板制作电子管。用部署器依次把小齿轮、大齿轮、铁粒加工到金板上；精密构件按实际成功件数备料。
3. 按原油勘探与抽取的界面顺序勘探、建井、抽油。先把原油收进独立储罐。
4. 用空的 `1×1×3` Create 流体储罐和蒸馏控制器组塔、接热源。自下而上接原油输入、柴油输出、汽油输出；各层管路分开，给机械泵供动力并核对朝向。
5. 先炼一批，确认成品进入对应储罐，并能泵入兼容的船用储罐。再实际炼出第二批。柴油和汽油都可供母星船使用；试飞、返航和着陆储备分别计算。

**完成条件：** 工坊能补产黄铜、电子管和精密构件，两批燃料已分别收取，输油路线能用。若只见原油罐下降、不见成品，先查热源、管路和输出罐。
