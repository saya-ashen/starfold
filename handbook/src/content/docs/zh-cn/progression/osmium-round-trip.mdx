1. 在 Atlas 比较砾星和砧星的距离、接近速度和已有探矿结果。两者都在母星系内，可用常规燃料。标记炉心基地，记下飞船、目的地、货物和各罐油量。
2. 把去程与返程分开估算，两边都计入起飞、转移、制动与着陆，另留着陆储备。带铁镐、食物、照明和维修件。驾驶时可用 `/starfold mark add home` 标记基地，用 `/starfold mark list` 核对。出发准备好再勾选计划任务。
3. 提前制动，选平坦且有净空的落点。停稳后标记飞船、矿点和退路，用铁镐采至少 **8 份原锇**，装进原船。按实际载货湿重、升力和各罐液位重算起飞和返程用油。油不够就停泊补给；完成装货复核后再勾选。
4. 用原船回炉心，核对飞船、原锇数量和各罐液位。先把至少 **8 份原锇**卸入基地仓库，再拿去冶炼。卸完再勾选。
