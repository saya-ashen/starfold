1. 备好船壳、强力胶、飞船控制器、推进器、陀螺仪、兼容储罐、货桶、舷梯和导航观察镜。舷梯装在舱门下方、朝外。先按你打算携带的燃料和货物布置船体。
2. 粘好预定船体，包括舱门上半部和驾驶设备，排除地面和支架。空手按住物理组装器右键，向上移动鼠标拉满后松开。检查实际捕获范围、喷口方向、舱门和舷梯。若组装器也被捕获，停稳后可用镐取回。
3. 少量加油，确认同船储罐可供推进器抽取，核对加油前后重量、升力与推力分布。确认船上的陀螺仪已通电，关闭推进器手动红石。登船后右键飞船控制器接管。
4. 在炉心空旷平地短时离地，低速移动、转向、提前制动并落地停稳。用[飞行键位](/zh-cn/reference/flight-controls/)核对操作和 HUD。停稳后下船、重新走舷梯登船，再练一次停泊维修。

**完成条件：** 同一艘船能起飞、可控制地停下并着陆，能下船重登，也能停泊维修。加油后飞不起来，先看湿重和供油，不要继续加满。
