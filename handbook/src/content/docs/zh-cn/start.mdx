本手册对应 **Minecraft 1.21.1 / NeoForge 21.1.247** 的 **Escape Velocity 单人生存 Alpha**。物品名称与配方以当前任务书和 JEI 为准。

1. 在独立实例中安装 [CurseForge 上的 Escape Velocity](https://www.curseforge.com/minecraft/modpacks/starfold-escape-velocity)，使用 Java 21 和整合包指定的模组版本。
2. 直接新建**单人生存世界**。开局没有赠送的飞船或停机坪，也没有下界和末地。更新整合包或改实例配置前，先备份存档。
3. 打开背包，从侧栏进入 **FTB Quests**。物品任务检查背包，进度与击杀任务记录游戏事件，有勾选框的手动任务要做完再勾。在 JEI 中指向物品，按 `R` 查配方、`U` 查用途。
4. 默认按 `M` 打开 Atlas，先标记基地。
