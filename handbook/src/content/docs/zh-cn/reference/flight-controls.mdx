登船后右键**飞船控制器**接管。以下为手册对应版本的默认键；若与实机不同，以当前 HUD 和「控制」设置为准。先在炉心本地试飞中确认效果。

| 场景 | 默认操作 | 怎么确认 |
| --- | --- | --- |
| 近地移动 | `W/S` 前后，`A/D` 横移，`空格/Shift` 升降，`Ctrl` 配合方向或升降加力 | 在空地短按，观察移动方向、高度和速度 |
| 近地姿态 | 鼠标左右转船头，`Q/E` 左右压翼，松手回正 | 看船头方向和姿态变化 |
| 太空驾驶 | 鼠标转向和俯仰，`Q/E` 滚转；`W/S` 前后推，`A/D` 横移，`空格/Shift` 升降 | 看相对目标的速度和距离，不以船头朝向代替航速读数 |
| 退出驾驶或中止自动抵达 | `R` 退出驾驶；如提示确认，再按同一键。自动抵达期间可用 `空格 + Ctrl` 中止，再主动飞离 | 降落停稳才下船；自动抵达不会替你选安全落点，在太空留在船上 |
| 个人飞行 | `空格/Shift` 升降，`Ctrl` 加速，`Alt` 直飞，`G` 制动 | 查个人飞行 HUD；这些不是飞船控制器的操作表 |
