默认按 `M` 打开 Atlas。用**地面图**记基地和矿口，用**星球图**看落点所在的面，用**星系图**比较行星与卫星，用**星际图**选另一个恒星系。

1. 在地面图给基地、停泊点和退路加航点。要选中或删除已有航点，切换到星球球面图，再点航点标记。 驾驶时也可用 `/starfold mark add home` 留基地标记，用 `/starfold mark list` 核对。
2. 找不到船时，先回停泊航点，再对照船只记录。探矿结果是历史记录；开采后的余量到现场确认。
3. 船上要有导航观察镜，并由你接管飞船控制器。驾驶时在 Atlas 对所选天体使用「设为导航目标」，回到飞行界面检查是否出现目标。点「接近」只移动观察视角。
4. 到了目的星系，在当地星系图选具体着陆行星，不要继续用整个星系作落点。参见采锇往返和远征。
