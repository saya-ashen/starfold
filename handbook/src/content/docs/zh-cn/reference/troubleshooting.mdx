---
title: "航行与故障"
---

<a id="pressure"></a>

## 气压过高

**立即停止深入，沿预选方向退出。** 对照整舰气压估计和采集口压力，在最弱暴露部件达到阈值前撤离。退出后查损伤、液位和推进余量。[采气 HUD 与压力判定](/zh-cn/progression/deuterium/)

<a id="braking"></a>

## 无法刹停

以目标相对速度判断是否在减速，留出制动距离。母星系外查同船引擎和可抽取的氘；惯性滑行不会自行刹停。

<a id="return-fuel"></a>

## 燃料不足

能安全停泊就停泊，保留剩余燃料并安排补给。检查各罐液位和供油链；母星系外的救援船也需要星际推进能力。

<a id="lift-off"></a>

## 飞船不起飞

查捕获范围、喷口方向、燃料兼容与抽取、陀螺仪通电和湿重。安全停泊后再减载或改装。

<a id="bucket"></a>

## 无法注液

给机械泵供动力，检查朝向和注液器供液；空桶放置物台或传送带，不直接右键普通储罐。

<a id="navigation"></a>

## 航点、导航目标或飞船找不到

回最后确认的停泊点，对照 Atlas 船只记录。导航不显示时，查是否接管原船、是否有导航观察镜、是否点了「设为导航目标」。

<a id="machines"></a>

## 机器不产出

逐项查原料、动力、应力、端口、泵方向和输出空间。蒸馏查热源，电解查氧气出口，抽油查现场勘探和井况。
