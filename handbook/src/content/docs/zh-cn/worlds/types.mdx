| 类型 | 看什么 | 去哪里看 |
| --- | --- | --- |
| 家园 | 有陆地与水岸，可找兼顾住处、矿口和工坊的地面 | [炉心](/zh-cn/worlds/hearth/) |
| 岩质 | 裸露岩面；从轨道看不出局部落点是否平坦 | [砧星](/zh-cn/worlds/anvil/) |
| 小行星 | 小型天体的轮廓与近地净空要分开看；别仅凭大小判定 Atlas 的世界类型 | [砾星](/zh-cn/worlds/fleck/)，炉心的卫星 |
| 繁茂 | 植被覆盖明显，落船前找开阔地 | [苍翠](/zh-cn/worlds/viridia/) |
| 群岛 | 水域分隔陆地，先确认岸线和岛上净空 | [群澜](/zh-cn/worlds/pelagia/) |
| 沙漠 | 沙质地表，也是铝土矿补给去处 | [赭沙](/zh-cn/worlds/saffron/) |
| 蘑菇 | 用蘑菇地貌辨认环境，不把菌盖当落点 | [菌港](/zh-cn/worlds/haven/) |
| 幽匿 | 观察幽匿覆盖与实际地面，别靠深色轮廓判断净空 | [寂痕](/zh-cn/worlds/hush/) |
| 末地 | 末地类型地表；从接近视角确认实际平台边缘 | [象牙](/zh-cn/worlds/ivory/) |
| 玄武岩 | 玄武岩地表，近看高差再选落点 | [烬岩](/zh-cn/worlds/cinder/) |
| 冰冻 | 冰面和起伏地形，亮面不一定平坦 | [霜原](/zh-cn/worlds/rime/) |
| 晶体 | 晶体地貌；要找萤石，近看矿物再采 | [晶棱](/zh-cn/worlds/prism/) |
| 血肉 | 巢脊和巢坑会截断步行路线，先找退路 | [血肉](/zh-cn/worlds/flesh/) |
| 气态巨行星 | 观察气层压力，不找地面落点 | [琥珀](/zh-cn/worlds/amber/) |
